# 흐름 문서 틀

주제 하나의 동작을 처음부터 끝까지 구간으로 나눠 서술하는 permanent 노트다. 시나리오와 그림으로 가는 입구이고, 맨 위의 읽는 순서가 학습 경로가 된다. 기준점: vault `30-resources/tech/java/JVM 구동방식.md`.

## 작성 규칙

- 제목은 `{주제} 동작방식: {시작점}에서 {끝점}까지`. 파일명은 `{주제} 동작방식.md`.
- 요약 콜아웃 첫 줄은 결론(무엇이 무엇을 거쳐 어떻게 되나)이다. 마지막 줄에 기준 버전을 적는다.
- `## 읽는 순서`는 요약 콜아웃 바로 다음이다. 이 노트의 절, 시나리오, 그림을 읽을 순서대로 링크한다.
- 구성 요소와 구간 표의 근거 칸도 비우지 않는다(시나리오와 같은 표기).
- 구간 번호(①, ② ...)는 시나리오 `구간` 열, 그림의 구간 표시와 같다.
- 그림은 `## 파생 다이어그램` 표에 모두 올린다. 그림을 고칠 때의 정본(JSON, 생성기 데이터 표)을 함께 적는다.
